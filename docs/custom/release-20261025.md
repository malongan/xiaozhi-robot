# 2026-10-25 版本说明：充电状态修复 + BOOT 长按关机

本版针对电池与交互做两项补强：让「插电显示充电」在这块没有 CHRG 回读的板子上真正可用，
并给 BOOT 键加上长按关机（deep sleep）能力。功能包组合与上一版一致，没有新增/删减功能包。

- 基线：`custom-final-20261023-r2`
- 本版标签：`custom-final-20261025`
- 详细功能包说明：[`feature-packs.md`](feature-packs.md)

## 一、适用硬件与升级方式

- 板型：**Freenove ESP32-S3 Display 2.8"**（16 MB flash / 8 MB PSRAM，SD 4-bit SDMMC）
- 分区：沿用 `partitions/v2/16m_app6m.csv`，**本版不改分区**
- 从上一版升级（保留 NVS、Wi-Fi 凭据、蓝牙配对与音乐索引）：

```bash
python -m esptool --chip esp32s3 -p /dev/cu.usbmodem31101 -b 460800 \
  --before default-reset --after hard-reset write-flash 0x20000 build/xiaozhi.bin
```

- 全新烧录（含 bootloader / 分区表 / assets）：

```bash
python -m esptool --chip esp32s3 -p /dev/cu.usbmodem31101 -b 460800 \
  --flash-mode dio --flash-freq 80m --flash-size 16MB \
  write-flash 0x0 build/bootloader/bootloader.bin 0x8000 build/partition_table/partition-table.bin \
  0xd000 build/ota_data_initial.bin 0x20000 build/xiaozhi.bin 0xc00000 build/generated_assets.bin
```

## 二、修复：插电不显示充电

### 问题根因

这块板子的充电 IC 是 **TP4054**，但它的 `CHRG` 状态脚**没有连到 ESP32 的任何 GPIO**
（原理图上 CHRG 仅作未使用脚处理，板上也没有充电指示灯）。原固件走的是
`adc_battery_estimation` 的软件趋势估算：

- 需要 10 次采样 × 20 秒 ≈ **3.3 分钟**才给出第一次结论；
- 只比较电池电压的升降，而充电末期电压几乎不动；
- 实测电池接近满电时（4.12 V）电压稳定在 ±4 mV，**实际已进入截止状态**，
  任何基于电压的推断都不可能判出「充电中」。

所以这不是某个开关没打开，而是原路径在该板硬件上不可靠。

### 本版做法

新增板级 `freenove_power_monitor.*`（不改共享的 `adc_battery_monitor`，不影响其余 7 个板），
自己读 `ADC1_CH8 / GPIO9`，用三级判定：

| 优先级 | 依据 | 生效场景 |
|---|---|---|
| 1 | `BATTERY_CHARGING_DETECT_PIN` 非 `NC` 时直读 CHRG（开漏，低=充电中） | 自行飞线改造后最准确 |
| 2 | 检测到 USB 主机（USJ SOF）→ 视为外部供电，电池 < 4.19 V 显示充电中 | 插电脑或数据线，**秒级** |
| 3 | 电池电压的插拔阶跃（20 s 内，阈值 12 mV）与 5 分钟斜率（阈值 8 mV） | 插纯充电头时兜底 |

同时修掉了原来的两个问题：

- 不再依赖 3.3 分钟的长窗口，插拔阶跃约 **20 秒**内给出结果；
- 没接电池（电压 < 2.5 V）时不再显示电池图标，避免误显示 0%。

### 已知限制

- 电池接近满电（TP4054 已截止）时**显示满格电池而不显示闪电**，这是符合实际的状态；
  若希望「只要插线就无条件显示闪电」，把 `freenove_power_monitor.cc` 里的
  `battery_mv_ < 4190` 判断去掉即可。
- 纯充电头（无 USB 数据）读不到 USJ，只能靠电压阶跃；电池满电时该路径也不会触发。
- 想要 100% 准确的充电状态，需要把 TP4054 的 CHRG 飞线到空闲脚
  （IO2/IO3/IO14/IO21 之一），加 10 K 上拉到 3.3 V，并把 `config.h` 的
  `BATTERY_CHARGING_DETECT_PIN` 改成该引脚。

## 三、新增：BOOT 长按关机

- **长按 BOOT 1.5 秒** → 静音、显示「正在关机」、关闭背光，进入 **deep sleep**
- **BOOT 键作为 ext0 唤醒源**，关机后再按一次即可开机
- **单击行为保持不变**：仍是切换对话 / 首次启动时进入配网

实现要点：进入 deep sleep 前会**等待按键松开**（最长 5 秒）。否则 GPIO0 仍为低电平时，
ext0 的低电平唤醒条件立刻满足，会出现「按一下就重启」的假关机。若一直按住则取消关机并恢复背光。

### 已知限制

插着 Type-C 时硬件仍在供电，deep sleep 只是把功耗降到最低、屏幕全灭；
**真正断电需要拔掉 Type-C 或电池**。这是该板没有电源锁存电路的固有限制。
