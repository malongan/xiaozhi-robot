# 2026-10-26 版本说明（r2）：空闲省电 + BOOT 深度关机 + INFO 日志

本版把「费电」这条线补齐：**空闲自动降背光 + 降频**、**长按 BOOT 真正断电（deep sleep）**，
并把默认日志级别从 `WARN` 提到 `INFO`，让串口重新可用。功能包组合不变，仍是 `daily`。

同时新增两份**只做分析、未改代码**的性能文档：`performance-analysis.md` 与
`optimization-checklist.md`，供后续按批次优化。

## 二、新增：空闲省电（设置页可配置）

### 之前为什么费电

这块板子**根本没有挂 `PowerSaveTimer`**，所以屏幕永远满亮、CPU 永远 240 MHz。
即使有的板子挂了，原实现进入省电时会 `EnableWakeWordDetection(false)` 并关掉音频输入，
在彩屏常驻设备上等于「省电 = 喊不醒」，不能这么用。

### 现在的行为

空闲到设定时长后：

- 背光降到**待机亮度**（默认 10%），不是全黑，保持可读
- CPU 动态调频 **240 → 40 MHz**（`esp_pm_configure`）
- **唤醒词检测与音频输入保持不变**，随时能喊醒
- 触摸屏幕、按 BOOT、或任意一次语音交互都会立刻恢复亮度

关键取舍：**不进 light sleep**。light sleep 会断 Wi-Fi 与音频链路，代价是会话不可达；
本版只要「降频 + 降背光」，连接与唤醒词全程保住。日志里会看到
`Light sleep: DISABLED`，这是预期值，不是故障。

### 设置页「空闲省电」卡片

设置页原来是固定高度铺满，加了卡片会溢出，故改为**竖向可滑动**（触摸屏直接上下拖）。

| 选项 | 默认 | 范围 / 步进 | 说明 |
|---|---|---|---|
| 空闲省电 | 开 | 开 / 关 | 总开关，关掉则永不降背光降频 |
| 空闲时长 | 60 s | 10 ~ 600 s，步进 10 s | 无操作多久进入省电 |
| 待机亮度 | 10% | 5 ~ 50%，步进 5% | 省电后的背光亮度 |

参数存在 NVS `power` 命名空间（`power_save_enabled` / `idle_seconds` / `standby_brightness`），
重启后保留。「重启设备」按钮下移到 y=420，仍在可滑动区域内。

### 代码改动

- `main/boards/common/power_save_timer.{h,cc}`：构造函数新增 `allow_light_sleep`、`keep_wake_word`
  两个参数（**默认值保持旧行为**，其它板子不受影响）；Freenove 传 `keep_wake_word=true`；
  `PowerSaveCheck` 中若 `in_sleep_mode_` 且已不能省电（如正在对话），主动 `WakeUp()`。
- `main/boards/freenove-esp32s3-display-2.8-lcd/*.cc`：新增 `InitializePowerSaveTimer()`；
  额外起一个 500 ms 轮询 `lv_display_get_inactive_time` 的定时器做触摸唤醒；BOOT `OnClick` 也 `WakeUp()`。
- `main/display/lcd_display.{cc,h}`：设置页开启竖向滚动，新增省电卡片。
- `scripts/feature_build.py`：`ALWAYS_APPEND` 打开 `CONFIG_PM_ENABLE` 与
  `CONFIG_FREERTOS_USE_TICKLESS_IDLE`——不开这两个，`esp_pm_configure` 调用是空转。

## 三、改进：BOOT 长按改为真正断电

上一版的长按关机只是 `deep sleep`，外设一个没关，屏幕常亮、功放带电、SD 卡还在供电，
待机电流下不来。本版按「先分级关断、再睡」重写 `PowerOff()`：

### 关机时序

1. 屏幕提示「正在关机」，等 900 ms 让提示画完
2. **等按键松开**（最多 5 s）。不等就睡的话，BOOT 低电平唤醒条件立刻满足，
   刚进 deep sleep 就被拽起来，现象跟重启一样
3. 静音 → 关功放输出（`EnableOutput(false)`）→ 关麦克风输入（`EnableInput(false)`）
4. 背光归 0；LED `TurnOff()`
5. 屏幕发 `DISPOFF(0x28)` + `SLPIN(0x10)`，面板进 sleep
6. 停 SD 重试定时器 + `esp_vfs_fat_sdcard_unmount`，让卡进 idle
7. `esp_sleep_pd_config(RTC_PERIPH, ON)`，然后 ext0 唤醒（BOOT，低电平）
8. `esp_deep_sleep_start()`

### 唤醒安全

ILI9341 驱动每次 init 都会发 `SLPOUT`，所以唤醒后屏幕自动恢复，不需要额外做状态复原。
实测长按关机后设备从 USB 总线消失（`VID_303A` 全部枚举不到），按 BOOT 可正常开机。

> 注意：关机后**电流无法用软件测量**，需外接功耗仪。本版只保证外设已关断。

## 四、变更：默认日志级别 WARN → INFO

`WARN` 级别下所有 `ESP_LOGI` 在**编译期**就被裁掉，串口一片空白，排查省电/SD/Wi-Fi
只能盯着小屏幕。本版改为 `INFO`：

```python
"CONFIG_LOG_DEFAULT_LEVEL_WARN": False,
"CONFIG_LOG_DEFAULT_LEVEL_INFO": True,
```

`CONFIG_LOG_MAXIMUM_EQUALS_DEFAULT=y` 时最大级别跟随默认值，无需单独写
`CONFIG_LOG_DEFAULT_LEVEL=3`。代价是串口日志变多、固件略大（约 +50 KB），可接受。

## 七、已知限制

- **空闲 30 s 触发不是 bug**：NVS `power/idle_seconds` 历史上被手动调成 50 → 40 → 30，
  设置页改动会覆盖它；想要 60 s 就在设置页调回去。
- **省电不省连接**：本版不启用 light sleep，Wi-Fi 常连，所以「静置一晚」的省电幅度有限，
  真正的低功耗需要 light sleep + 重连策略，属后续改动。
- 关机电流无法软件测量，需外接功耗仪确认。
- 其它板型未接 `PowerSaveTimer` 的保持原状；`keep_wake_word` 默认 `false`，行为不变。
