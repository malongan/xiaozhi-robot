## 二、踩坑与经验

### 1. 主题刷新崩溃（PC=0, InstrFetchProhibited）
- 现象：资源加载/主题刷新时随机重启，栈在 `lv_label_event → lv_font_get_glyph_width`。
- 原因：非聊天页（笔画页/设置页）标签在 SetupUI 用当时主题字体创建，主题刷新时旧字体被释放，但标签仍持有旧指针；任何布局触发 label 重算尺寸就踩空。
- 修复：`SetTheme` **最开头、任何样式传播之前**把全部非聊天页标签字体重绑到新主题字体；`ApplyChatLayout` 再兜底。
- 教训：**凡是"创建一次后不在 ApplyChatLayout 里"的标签，必须纳入 SetTheme 开头的重绑列表**。

### 2. TF 卡"假写入"（坏卡）
- 现象：Mac 上格式化+拷贝都成功、校验也一致，设备端只看到旧目录；断电后新文件消失；最后格式化把磁盘工具卡死（进程 U/?E 状态，kill -9 无效）。
- 原因：卡/卡套处于写保护或坏卡，写入被静默丢弃。
- 验证方法：写测试文件 → 弹出 → 重新插入（或断电重启）→ 文件还在才算真写入。
- 解决：换卡。拔读卡器才能释放内核挂起进程。

### 3. macOS 向 FAT32 写入错乱
- 现象：`cp` 拷完立即校验一致，但设备读到的是乱码/旧内容；文件大小相同、内容不同。
- 解决：改用 `dd if=... of=... bs=4096 conv=fsync` 重写后校验一致；写完 `sync` 再弹出。

### 4. 字模下部裁切（数据问题，不是固件问题）
- 现象：部分字（如"学"）底部笔画被切掉。
- 原因：生成器把 1024 网格轮廓直接乘 `160/1024` 再 `+4` margin，字轮廓可超出 1024 em box（如 -46），底部/右侧被 160px 位图裁掉。
- 修复：**按每个字的实际轮廓包围盒等比缩放 + 6px 安全边**，并把笔顺中位线（medians）用同一套仿射变换，保证动画和底图对齐。

### 5. 笔画演示退不出的根因（状态机）
- 现象：新对话开始后笔画页不退出。
- 错误假设：以为新对话一定经过 `Idle → Listening/Thinking`。
- 实际：设备是自动聆听模式，AI 答完回到 `Listening`，用户接着说新问题走 `Listening → Speaking`，**不经过 Idle**。
- 修复：在**用户语音识别结果（STT）到达**时关闭覆盖页（以及唤醒词/会话结束/手动关闭作为其他出口）。
- 教训：交互退出条件要挂在**明确的用户动作事件**上（STT、唤醒、按键、触摸），不要靠状态枚举推断。

### 6. 触摸不灵敏
- 原因：按钮用 `LV_EVENT_CLICKED`（松手才触发），且小按钮实际热区只有 36px。
- 修复：`LV_EVENT_PRESSED` + `lv_obj_set_ext_click_area(btn, 8~12)`。

### 7. 音量持久化的 NVS 磨损
- `AudioCodec::SetOutputVolume()` 每次都会写 NVS。
- 之前"睡眠呼吸声"每 4 秒调一次音量（85→恢复 70），一天下来 NVS 被写几百次；已移除该功能。
- 教训：**不要周期性调用会持久化的 setter**（音量/亮度等），需要临时值用非持久化接口或直接改内部变量。

### 8. 串口被后台任务占用
- 后台抓日志进程持有 `/dev/cu.usbmodem31101`，`esptool write-flash` 失败并提示 troubleshooting。
- 解决：刷机前 kill 掉读串口进程。

### 9. 其他
- `LV_OPA_15` 不存在（只有 0/10/20...），编译报错。
- 设置页/笔画页的按钮回调命名与已有蓝牙按钮 `OnBtDisconnectClicked` 冲突，需加前缀。
- 删除代码块时注意连带删除后续 lambda 依赖的局部变量（`stroke_key_slot`），否则编译报错。

## 三、数据管线位置

- 生成器：`xiaozhi-robot/tools/stroke-pipeline/`（`build.py` / `verify.py` / `fetch.py`）
- 卡上数据：`tools/stroke-pipeline/sdcard/`（index.bin / medians.bin / pinyin.json / glyphs/g1..g6.bin）
- 扩展字库：`build_charset(extend=True)` 把 hanzi-data 全部 9516 字收进来（缺"浥"），实际 9470 字
- 换卡后重生成：`PYTHONPATH=.deps python3 build.py`，再按第 3 条用 dd 写卡
