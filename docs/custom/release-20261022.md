# 定制版 2026-10-22 · 设置/网络卡片 + 三面板键盘 + 6MB OTA 分区

- 版本：`custom-final-20261022`
- 适用硬件：Freenove ESP32-S3 Display 2.8"（ESP32-S3 / 16MB Flash / 8MB PSRAM）
- 上游基线：xiaozhi-esp32 `v2.5.2`
- 源码分支：`avatar-5line` / `main`

## 本次更新

### 设置页

- 改成卡片式布局：声音与显示、连接、重启三块区域，信息层级更清楚。
- 音量、亮度直接显示百分比，麦克风增益显示 `dB`。
- WiFi 增加连接状态点和 SSID，和 IP 分两行显示，长名称自动省略。
- 蓝牙保留连接状态、断开、清空配对；重启按钮改为整行危险色描边样式。

### 网络页

- 文件传输页改成卡片式：文件服务、WiFi/IP、SD 容量、传输进度四块。
- 文件服务显示运行状态、访问地址、同一 Wi-Fi 提示，可手动启动/停止。
- SD 卡显示已用比例进度条和剩余容量；拔卡时显示“未插入 SD 卡”。
- 上传时显示文件名、上传百分比、完成/失败状态，失败为红色、完成为绿色。
- 设置页与网络页的图标、状态点、标签在主题刷新时统一重绑字体。

### BLE 三面板键盘

- 媒体页标题可点击循环切换：`媒体` → `全键盘` → `数字键`。
- 全键盘支持 A–Z、常用符号、Shift/大写、退格、空格、发送。
- `中` 键发送 `Ctrl+Space`，交给主机切换输入法。
- 数字键面板支持数字、四则运算、回车和方向键。
- 打开媒体页自动回到媒体面板，不再停留在上次的键盘面板。

### 功能抽屉与听写

- 首页底部把手展开功能抽屉，二级页返回时回到抽屉而不是待机画面。
- 英语听写范围列表改为分页，左右侧点按切上一个/下一个，页头可返回/重置。
- 听写支持重新开始本轮，继续保留课文/分类两种范围。

### 网页传文件

- 浏览器可浏览、上传、下载、删除 SD 卡文件，支持新建文件夹。
- 可选 PIN 访问；只在 STA 网卡监听，同一局域网使用。
- 设备连上 Wi-Fi 自动启动，断网或配网模式自动停止。
- 详细接口与限制见 [`docs/web-file-transfer.md`](../web-file-transfer.md)。

### 16MB Flash 新分区

- 新增 `partitions/v2/16m_app6m.csv`，仅用于 Freenove 16MB 板。
- 单个 OTA 槽从 4,128,768 B 提升到 6,225,920 B（约 5.94MB）。
- assets 从 8MB 缩到 4MB；当前资源包约 1.2MB，仍余约 2.8MB。
- 当前固件约 3.48MB，单个 app 槽剩余约 2.62MB。
- 全局 `partitions/v2/16m.csv` 未改，其他板不受影响。

## 升级前必读

**这次改了分区表，不能只靠 OTA 从 20261021 及更早版本升级。**

- 分区表不能通过 OTA 更新；首次升级必须用 USB 写一次分区表、otadata、app 和 assets。
- 推荐先完整备份 16MB Flash，再刷机；回滚需要整片镜像或旧分区表 + app + NVS。
- 使用下文的“迁移刷机”命令会保留 NVS（WiFi/激活/设置），不会写 `0x9000`。
- 使用完整镜像 `0x0` 会擦除 NVS，WiFi/激活需要重新配置。
- 旧 8MB assets 中额外下载的主题、字体、模型不会自动迁移；需要重新下载或从备份恢复。
- `otadata` 会重置到 `ota_0`，首次启动后由 bootloader 重新记录启动槽。

## 镜像

| 文件 | 写入地址 | 说明 |
|---|---|---|
| `xiaozhi-custom-final.bin` | `0x0` | 16MB 完整镜像，会清空 NVS/激活信息 |
| `xiaozhi-app-only.bin` | `0x20000` | 仅应用，保留 NVS；要求已经是新分区表 |
| `bootloader.bin` | `0x0` | 迁移刷机用 |
| `partition-table.bin` | `0x8000` | 新 6MB app 分区表 |
| `ota_data_initial.bin` | `0xD000` | 重置 OTA 选择到 `ota_0` |
| `generated-assets.bin` | `0xC00000` | 4MB assets 资源包 |
| `sdcard-data.zip` | TF 卡根目录 | 笔顺数据（9470 字，可选） |
| `english-v5-sdcard.zip` | TF 卡根目录 | 英语词库 v5（1220 词，可选） |

## 迁移刷机（保留 NVS）

先备份，再执行：

```bash
python3 -m esptool --chip esp32s3 -p /dev/cu.usbmodem31101 -b 460800 \
  --before default-reset --after hard-reset write-flash \
  --flash-mode dio --flash-freq 80m --flash-size 16MB \
  0x0 bootloader.bin \
  0x8000 partition-table.bin \
  0xD000 ota_data_initial.bin \
  0x20000 xiaozhi-app-only.bin \
  0xC00000 generated-assets.bin
```

## 全新刷机（清空 NVS）

```bash
python3 -m esptool --chip esp32s3 -p /dev/cu.usbmodem31101 -b 460800 \
  --before default-reset --after hard-reset write-flash \
  --flash-mode dio --flash-freq 80m --flash-size 16MB \
  0x0 xiaozhi-custom-final.bin
```

## 后续升级

分区迁移完成后：

- 只改应用：写 `xiaozhi-app-only.bin` 到 `0x20000`，或走 OTA。
- 只改资源：写 `generated-assets.bin` 到 `0xC00000`。
- 再次改分区表：仍需 USB 刷写，不能 OTA。

## 已知限制

- 网页传文件是局域网 HTTP，PIN 为明文比对；不可信网络请设置 PIN 或不要开启。
- BLE 键盘的中文输入依赖主机输入法和 `Ctrl+Space` 切换；不同系统快捷键可能不同。
- 新 assets 分区只有 4MB，新增模型/字体/语音前先计算容量；超限需重新规划分区。
- 完整镜像会清空 NVS；日常升级优先用 app-only 或 OTA。
