# 2026-10-22 定制固件 r3 版本说明：听写语音调节 + 同词循环/拼音修复

本版是 2026-10-22 定制固件的第三个版本（r3），基于 r2。重点是补齐英语听写中的
"唤醒后只做后台语音调节"链路，并修复双语模式下同一个单词无限重播、笔顺拼音在
8192 字之后缺失的问题。

- 基线：`custom-final-20261022-r2`
- 分支：`fix/english-word-repeat`
- 标签：`custom-final-20261022-r3`
- 发布状态：**已发布**。代码已构建、刷入，并通过实机语音验收。

## 一、适用硬件与升级方式

- 板型：**Freenove ESP32-S3 Display 2.8"**（16 MB flash / 8 MB PSRAM）
- 分区：沿用 `partitions/v2/16m_app6m.csv`，**本版不改分区、不改 assets**
- 从 r2 升级：只烧 app 到 `0x20000`，保留 NVS、WiFi 凭据、蓝牙配对和 SD 数据

```bash
python3 -m esptool --chip esp32s3 -p /dev/cu.usbmodem31101 -b 460800 \
  --before default-reset --after hard-reset write-flash 0x20000 build/xiaozhi.bin
```

本版不涉及 bootloader、分区表、assets，因此不需要重新执行完整迁移刷机。

## 二、新增：听写中的后台语音调节

### 使用流程

1. 进入英语听写，设备退出服务器 ASR 监听，但**保留唤醒词检测**。
2. 说唤醒词"你好小智"，英语页面保持在前台，不切屏，听写暂停。
3. 设备进入约 **5 秒**的语音调节窗口，可继续说：
   - "改成中文" / "改成英文" / "中英文都读"
   - "间隔改成 5 秒" / "改成手动翻页"
   - "下一个" / "上一个" / "重播"
4. 助手 TTS 回复期间暂停 5 秒计时；回复结束后重新给 5 秒。
5. 5 秒内没有新的调节命令：停止监听，恢复听写，保留当前单词和倒计时。
6. 只有说"退出听写"（助手调用 `self.english.stop`）或点击返回，才关闭听写页面。

### 实现要点

- 听写模式使用 `Application::SetDictationActive(true/false)` 标记。
- 唤醒词触发 `dictation_command_mode_`，听写只暂停不停止，页面保持。
- 调节命令轮次使用 `kListeningModeAutoStop`；5 秒宽限由本地定时器控制。
- 5 秒计时在以下时机重置：
  - 唤醒进入命令模式；
  - 进入 `kDeviceStateListening`；
  - VAD 变化；
  - 助手 TTS `stop` 后。
- 助手 TTS `start` 时取消当前 deadline，避免回复中途超时。
- 超时后 `StopListening()`，进入 Idle 再调用 `EnglishPlayer::Resume()`，避免本地
  单词播放与服务器 ASR 切换重叠。
- 听写中忽略 BOOT/麦克风对话按键，避免误触进入普通对话。
- 听写中唤醒不再调用 `LcdDisplay::ShowEnglishScreen(false)` 关闭页面。

## 三、新增 MCP 工具

| 工具 | 作用 |
| --- | --- |
| `self.english.speak` | 调整播报语言：0 英文、1 中文、2 中英；不重开、不跳词 |
| `self.english.interval` | 调整自动翻页间隔：0–120 秒，0 为手动；不重开、不跳词 |
| `self.english.stop` | 结束听写并关闭学习页；仅用户明确要求退出时调用 |

同时调整：

- `self.english.dictation` 在同一轮听写中改语言/间隔/显示方式时只更新参数，
  不再回到第一个词。
- `self.english.cards` 对同一范围、同一间隔的重复请求改为幂等，不重启动。
- 听写工具描述明确要求：只调节语言或间隔时优先调用 `speak` / `interval`，
  不要重新开始。

## 四、修复

### 1. 双语模式同一个单词无限重播

根因：`EnglishPlayer::PlayCurrent()` 在双语分支成功播出英文后，没有清掉
`retry_current_`；`Tick()` 每 200 ms 又把当前词当成"设备忙"重试，形成死循环。

修复：

- 英文成功播出后立即清 `retry_current_`；
- 修正 `Tick()` 在设备忙时的推进语义，保留 `retry_current_`，不再回滚并清标记；
- `self.english.repeat` 增加 800 ms 去抖，避免助手连续调用变成连播；
- 设置播报语言改为幂等 `SetSpeak()`，不再用 `CycleSpeak()` 循环到目标值；
- 开始听写时只设置语言，不先重播旧词。

### 2. 笔顺拼音在 8192 字之后缺失

根因：`StrokeStore::LoadPinyin()` 的解析上限是 8192 条，而 `/sdcard/pinyin.json`
实际有 9471 条。

修复：

- 上限从 8192 提高到 10000；
- 启动日志增加 `pinyin=%d`，便于确认实际加载数量；
- 实机确认 `py_count_=9471`，`静=jìng` 等后段字符可正常显示。

## 五、行为变化（升级需知）

1. 听写中唤醒不再退出听写，而是进入后台语音调节；页面保持。
2. 唤醒后如果 5 秒内不说话，会自动停止监听并继续听写，不需要再点屏幕。
3. "改语音"当前指**播报语言**（英文/中文/中英），不是音色切换。
4. 听写中 BOOT/麦克风按键不进入普通对话；屏幕返回和停止仍可退出。
5. "退出听写"依赖助手调用 `self.english.stop`；本版没有加入本地关键词识别。
6. 5 秒窗口是本地宽限时间，不是服务器 VAD 的固定值；助手回复期间会暂停计时。

## 七、已知问题

1. 语音调节依赖助手模型正确选择 `self.english.speak`、`self.english.interval`、
   `self.english.stop`；模型未调用时不会本地兜底。
2. "退出听写"目前没有本地关键词检测；如果模型不调用 `stop`，页面不会自动关闭。
3. "改语音"不支持音色切换；需要音色时应另做语音包/音色功能。
4. `assets.bin size ... exceeds partition limit 100 bytes` 是现有构建告警，
   host tests 仍以 exit=0 通过，本版未改变 assets 布局。
5. `E Dynamic Impl: mbedtls_ssl_fetch_input error=76` 为历史网络错误，与本版无关。
6. 听写命令模式使用服务器 auto-stop 与本地 5 秒定时器，极端网络抖动下仍可能有
   状态切换竞争，需要继续观察串口日志。
